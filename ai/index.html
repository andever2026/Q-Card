Make your vocab sets with AI

Give the link to this page to your AI assistant (Claude, ChatGPT, Gemini or another), along with your vocab material: a photo of the list, a PDF page, or text you paste in. It will make a file you can import.

  1. Send your AI this page's link and your vocab list. You could say:

    Read this page and make me a Japanese Vocab Practice import file from my vocab list: [this page's link]

  2. It gives you a file ending in .json.
  3. In Japanese Vocab Practice, open Settings (the gear), choose Import a file…, pick that file, check the preview and import it.

AI can misread a blurry photo, so look over the words before you practice. You can fix any word later in the vocab table. Please don't share files copied from textbooks publicly.

For AI assistants: how to make the import file

The person who gave you this link wants their Japanese vocab material turned into a file they can import into Japanese Vocab Practice, a site where they write each word by hand and get it checked. This section describes that file. It asks nothing of you beyond making it.

What to do

  1. Read the material the person gave you. Use only the words in it: don't add, drop or reorder words, and keep the wording, readings and spellings as the material prints them. If part of it is unreadable or unclear, ask the person instead of guessing.
  2. If the material has sections (lettered word lists, a kanji list, extra phrases), make each section its own set. If it has no English meanings, write short common ones and tell the person you added them.
  3. Build one JSON file in the format below.
  4. Give the person the file. If you can create files, make a downloadable file named something like my-vocab.json. If you can't, put the whole JSON in one code block and tell them to save it as a plain text file ending in .json.
  5. Tell them how to import it: open Settings (the gear) in Japanese Vocab Practice, choose Import a file…, pick the file, check the preview, then import.

Privacy

  • The file is for this person's own study. Give it only to them, and don't post it, publish it or suggest sharing it, especially when the material comes from a textbook or other copyrighted source.
  • Don't put the person's name or other personal details in the file.

The file format

One JSON object, UTF-8:

app
Always "jp-vocab-practice". A file without it is refused.
version
Always 2.
sets
The vocab sets, each one an object with the fields below. Required.
kanji
Optional. Kanji lists, one per unit, for the site's "Kanji learned up to" setting. Add them only when the material lists the kanji a unit teaches.
collections
Optional. { "order": ["Collection name", …] }: the order the collections are studied in.

Leave out courses and exportedAt: a file made for import doesn't need them.

Each set

id
Unique in the file. Letters, digits, -, _ and . only, starting with a letter or digit, at most 100 characters. Build it from the names, like genki-1-lesson-3-food. Importing replaces any set the person already has with the same id, so make ids specific.
collection
The textbook or course, like "Genki 1" or "Japanese 101". Up to 100 characters.
unit
The chapter, lesson or week, like "Lesson 3" or "Week 2". Up to 60 characters. Units sort with their numbers in order.
name
The set's name within its unit, like "Food and drink" or "A · Greetings". Up to 200 characters. Names starting with "Kanji", "Extras" or "Supp" sort after the others in their unit.
tags
Optional. Up to 12 short labels, like ["Verbs", "Quiz 3"].
words
The words, in the material's order, each { "id", "en", "kana", "kanji" }. Up to 3,000 per set.

Each word

id
Unique within its set, like "w1", "w2".
en
The English meaning, as the learner will write it. Separate alternative meanings with commas ("many, much"). Start verbs with "to" ("to eat") so the site's verb practice finds them. Short notes can go in parentheses ("hot (weather)").
kana
The reading in hiragana, or katakana for katakana words, as the material gives it.
kanji
The word written with kanji as the material gives it, or "" when it's written in kana only. No readings or furigana in brackets here.

Notation inside kana and kanji (use the full-width characters):

  • ／ between accepted alternatives: "なに／なん". When kana and kanji both list alternatives, list them in the same order.
  • （ ） around an optional part: "（お）てんき" with "（お）天気". Na-adjectives: "しずか（な）" with "静か（な）".
  • 〜 for the blank in a pattern: "〜さん".
  • Phrases and short sentences are fine as words, with their punctuation: "いま、なんどですか。" with "今、何度ですか。".

Each kanji list (optional)

{ "id", "collection", "unit", "kanji" }: the same id rules as sets, the collection and unit it belongs to, and the unit's new kanji as one string, like "食飲水".

Example

A made-up list, to show the shape:

{
  "app": "jp-vocab-practice",
  "version": 2,
  "sets": [
    { "id": "my-japanese-week-1-food", "collection": "My Japanese", "unit": "Week 1", "name": "Food and drink", "tags": ["Verbs"],
      "words": [
        { "id": "w1", "en": "to eat", "kana": "たべる", "kanji": "食べる" },
        { "id": "w2", "en": "to drink", "kana": "のむ", "kanji": "飲む" },
        { "id": "w3", "en": "water", "kana": "みず", "kanji": "水" },
        { "id": "w4", "en": "coffee", "kana": "コーヒー", "kanji": "" },
        { "id": "w5", "en": "tasty, delicious", "kana": "おいしい", "kanji": "" }
      ] },
    { "id": "my-japanese-week-1-weather", "collection": "My Japanese", "unit": "Week 1", "name": "Weather",
      "words": [
        { "id": "w1", "en": "weather", "kana": "（お）てんき", "kanji": "（お）天気" },
        { "id": "w2", "en": "quiet", "kana": "しずか（な）", "kanji": "静か（な）" },
        { "id": "w3", "en": "what", "kana": "なに／なん", "kanji": "何" },
        { "id": "w4", "en": "What's the temperature now?", "kana": "いま、なんどですか。", "kanji": "今、何度ですか。" }
      ] }
  ],
  "kanji": [
    { "id": "my-japanese-week-1", "collection": "My Japanese", "unit": "Week 1", "kanji": "食飲水天気静何今度" }
  ],
  "collections": { "order": ["My Japanese"] }
}

Before you hand it over

  • It's valid JSON, with "app": "jp-vocab-practice" and "version": 2.
  • Every set id is unique and specific, and word ids are unique within each set.
  • Every word has kana, and every word from the material is there, in order.

Importing adds new sets and replaces ones with the same id. It never deletes anything, and the person sees a preview before anything is saved.
